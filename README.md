# Prompt Lab

중학교 3학년 진로 연계 수업 1차시에 쓰는 웹사이트. 학생이 관심 분야의 문제를 찾고, AI와 함께 기능과 화면 순서를 정해 앱을 만들 최종 프롬프트를 완성한다. 2차시에는 이 사이트를 쓰지 않고, 완성한 프롬프트로 Canva Code에서 앱을 만든다.

처음 기획서는 [docs/prompt-lab-spec.md](docs/prompt-lab-spec.md)에 있다. 이후 실제 수업 내용에 맞춰 범위를 줄였으므로, 기획서의 앱 생성·Before/After 비교·Level 1~3 예시는 지금 사이트에 없다.

## 실행

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 배포 전 확인
```

## 구성

| 경로 | 내용 |
| --- | --- |
| `/` | 소개, 오늘 할 세 단계 |
| `/studio` | 세 단계로 프롬프트 만들기 |

### `/studio`의 세 단계

1. **문제 찾기** — 진로 분야 12개 중 하나를 고르면 그 분야의 문제 상황 예시 3개가 나온다. 고르거나 직접 써서 "누가 쓰는 앱인지"와 "어떤 문제를 해결하는지"를 정한다. AI를 쓰지 않는다.
2. **기능 정하기** — 학생이 AI에게 보낼 글을 쓰면 AI가 기능 5개를 제안한다. 학생이 쓸 기능을 고르고, 직접 추가할 수도 있다. 고른 기능은 AI를 다시 부르지 않고 브라우저에서 프롬프트로 합친다.
3. **화면 순서 정하기** — 학생이 앱 이용 순서를 적으면 AI가 2단계 프롬프트와 합쳐 최종 프롬프트로 정리한다. 순서를 쓰기 어려우면 "AI가 제안한 순서 받기"로 초안(최대 7단계)을 받아 고쳐 쓸 수 있다. 복사, TXT 내려받기, Canva 열기를 제공한다.

학생 한 명당 AI 호출은 기본 2번(기능 제안 1번, 최종 정리 1번)이고, 순서 초안을 받으면 3번이다.

콘텐츠는 `src/content/`에 있고 코드 수정 없이 글만 고칠 수 있다.

- `careers.ts` — 분야와 문제 상황 예시

## AI 기능

| 경로 | 하는 일 |
| --- | --- |
| `POST /api/suggest` | 사용 대상과 문제가 담긴 글을 받아 앱 소개, 기능 제안, 잘 쓴 점을 구조화된 JSON으로 돌려준다 |
| `POST /api/flow` | 학생이 정한 프롬프트를 받아 앱 이용 순서 초안을 4~7단계로 돌려준다 |
| `POST /api/finalize` | 학생이 정한 프롬프트와 이용 순서를 받아 최종 프롬프트, 정리한 점, AI가 채운 기본값을 돌려준다 |
| `GET /api/status` | AI 사용 가능 여부와 접속 코드 필요 여부 |

LLM 호출은 `src/lib/llm/`에만 있다. 모델을 바꾸려면 `client.ts` 또는 환경변수만 고치면 된다.

### 환경변수

`.env.example`을 `.env.local`로 복사해 채운다. Vercel에는 같은 이름으로 등록한다.

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | 예 | 워크스페이스 범위로 발급한 키. 없으면 2·3단계는 AI 없이 직접 쓰는 방식으로 동작한다 |
| `CLASS_ACCESS_CODE` | 아니오 | 설정하면 이 코드를 입력한 사람만 AI 기능을 쓸 수 있다. 공개 배포 시 설정 권장 |
| `PROMPTLAB_MODEL` | 아니오 | 기본값 `claude-opus-5-5` |
| `LIMIT_SUGGEST_PER_HOUR`, `LIMIT_FLOW_PER_HOUR`, `LIMIT_FINALIZE_PER_HOUR`, `LIMIT_TOTAL_PER_DAY` | 아니오 | 기본값 15, 15, 15, 600 |

### 알아 둘 것

- 횟수 제한은 서버 메모리에 저장한다. Vercel에서는 인스턴스마다 따로 세어져 정확한 상한이 아니다. 비용의 최종 상한은 Claude Console의 워크스페이스 지출 한도로 건다.
- 학생이 쓴 글은 서버에 저장하거나 로그로 남기지 않는다. 작성 내용은 학생 브라우저의 LocalStorage에만 있다.
- 전화번호, 이메일, 주민등록번호로 보이는 내용이 있으면 AI로 보내지 않고 거절한다.
